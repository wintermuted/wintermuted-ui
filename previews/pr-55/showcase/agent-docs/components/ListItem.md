# ListItem

Import `ListItem` from `@wintermuted/ui-react`. Load `@wintermuted/ui-theme/index.css` explicitly; React components do not inject CSS.

## Contract

Semantic ul/li/nav; `as` supports other elements or router links without a router dependency. Label navigation regions and use `aria-current="page"` on active links. Compose grid/flex layout in your application.

Related exports in this contract: [ListGroup](./ListGroup.md), [Nav](./Nav.md).
