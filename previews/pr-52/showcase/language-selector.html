Language selector

Native select and custom listbox variants, equivalent to React LanguageSelector.

Native select

Prefer the native .wm-select when a custom popup is unnecessary. The application owns translation and persistence; this component only chooses a value.

Custom listbox

Use .wm-language, .wm-language-trigger, .wm-language-menu and .wm-language-option from styles/components/language-selector.css. Opening focuses the selected enabled option. Arrows wrap, Home/End jump, Enter/Space select, Escape restores trigger focus, and Tab or outside activity dismisses without trapping focus.

Selected language: English

The trigger is disabled if all options are disabled. Labels and options belong to the caller. React counterpart.
