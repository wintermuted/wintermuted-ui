# ToggleGroup

Import `ToggleGroup` from `@wintermuted/ui-react`. Load `@wintermuted/ui-theme/index.css` explicitly; React components do not inject CSS.

## Contract

Controlled `value`, `onChange(value)` and typed `options` with labels, icons, swatches and disabled flags. `appearance`: segmented (default), outline, swatches (separated buttons with round color chips); `orientation`: horizontal or vertical; optional `fullWidth`. Uses canonical toggle-group CSS.
