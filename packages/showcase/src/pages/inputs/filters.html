Filters

Faceted selection and a responsive non-modal panel, equivalent to React FacetFilter and FilterPanel.

Responsive FilterPanel

Use .wm-filter-bar.wm-filter-panel and its slots from styles/components/filter-panel.css. Controls are inline above 48rem and disclosed below it. Close, scrim and unconsumed Escape restore toggle focus. Controls stay mounted; there is no focus trap or scroll lock. A nested disclosure consumes Escape before the outer panel.

FacetFilter reset, counts and empty state

Use .wm-facet-filter and .wm-checkbox-filter-* from styles/components/checkbox-filter.css. Reset is separate from a real value named all. Counts, unavailable options and the show-more labels belong to the caller. Hiding extra options must not discard selection.
