Color picker

Named swatches and custom colors with the same structure as React ColorPicker.

Swatches and custom input

Use the .wm-color-picker family from styles/components/color-picker.css. The default popup sits above its trigger. .wm-color-picker-right moves it to the right, returning above on narrow screens. Group and color labels must describe the choices without relying on color alone.

Document accent

Palette

Enter three or six hexadecimal digits, for example #137333.
Selected color: #2a4a8a

A swatch selects and closes. Custom input normalizes three/six-digit hex on blur; Enter commits and closes only valid input. Invalid input retains the previous selection and announces an error. Escape restores summary focus; outside clicks dismiss. Set disabled on swatches and both inputs for a read-only picker. These explicit sample colors are user data, not theme tokens. React counterpart.
