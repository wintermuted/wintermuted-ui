Guidelines

  • Use short headers and keep high-value columns leftmost.
  • Avoid more than 6-7 visible columns on desktop without horizontal segmentation.
  • Represent status with concise text and consistent vocabulary.

SortableTableHeader

Use .wm-sort-head, .wm-sort-btn and .wm-sort-dir-btn from styles/components/table.css. The column button selects the sort column; the separate direction button selects that column and reverses direction. Set aria-sort on the th, not the button. The application owns sorting; this demo actually reorders rows.
