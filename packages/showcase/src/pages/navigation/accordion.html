Accordion

Native disclosure with the same markup and styles as React Accordion.

Details and summary

Use .wm-accordion and .wm-accordion-body from styles/components/accordion.css. Enter or Space toggles the summary; the browser supplies expanded semantics. Add open for an initially expanded item.

Installation requirements
Load the theme stylesheet once. No React or JavaScript is needed.
Can multiple sections stay open?
Yes. Each disclosure is independent; hidden content remains mounted.

For a separate header action, use ActionDisclosure, not an interactive button nested inside summary. React counterpart.
