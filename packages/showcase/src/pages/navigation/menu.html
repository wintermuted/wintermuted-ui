Menu

Action menus with explicit focus and dismissal behavior, equivalent to React Menu.

Actions and disabled items

Use .wm-menu and .wm-menu-items from styles/components/menu.css. Arrow Down opens at the first enabled item; Arrow Up opens at the last. Arrows wrap, Home/End jump, Enter activates, and Escape restores trigger focus. Tab closes without trapping focus. Outside pointer activity and focus leaving the menu dismiss it.
