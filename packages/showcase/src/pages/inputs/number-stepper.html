Number stepper

Bounded incremental values with the same button-based interaction as React NumberStepper.

Bounds and fractional steps

Use .wm-stepper and .wm-stepper-value from styles/components/number-stepper.css. Both buttons use native Enter/Space activation. Values must be finite and within bounds; step must be positive. Clamp the final step and round decimal increments to avoid floating-point display artifacts.
