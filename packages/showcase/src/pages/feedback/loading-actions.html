Loading and action disclosures

Refresh, recovery feedback and independent header actions, equivalent to React RefreshAction, LoadStatus and ActionDisclosure.

RefreshAction

Compose .wm-btn from styles/components/button.css with an explicit type="button". Loading takes precedence over error/idle text, sets aria-busy and disables activation. The application owns the operation and completion, not a built-in timer.

LoadStatus

Use .wm-load-status, .wm-load-status-warning and retry/loading slots from styles/components/load-status.css. Idle has no visible or announced status. Errors use alert semantics, warnings use status semantics, and retry calls each supplied recovery action once. Optional help should receive the exact combined message and error/warning tone.

ActionDisclosure

Use the .wm-action-disclosure slots from styles/components/action-disclosure.css. The heading trigger and labeled header action are separate buttons. Start expanded, keep hidden content mounted, run collapse cleanup before hiding, and expand before the action callback. Post-render focus belongs to the host.
