Inline Panels — .inline-panel

Tonal in-context info blocks used inside cards or below form fields. Lighter and more contextual than a full .alert bar — surface information at the point of relevance without interrupting the page flow.

Canonical Badge and Alert

React Badge and Alert use .wm-badge-* and .wm-alert-* tone classes from styles/components/badge.css and styles/components/alert.css. Alert defaults to a polite status; use role alert for an urgent error. Text must convey the meaning of the tone.

ProgressBar

Use native progress and .wm-progress from styles/components/progress.css. Supply a positive maximum and clamp the value between zero and that maximum. A progress element without value is indeterminate; React ProgressBar defaults to a determinate zero.
