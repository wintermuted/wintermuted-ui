Document primitives

Page headings, breadcrumb trails and image fallbacks with the same styles as their React counterparts.

PageHeader

Use .wm-view-header.wm-page-header and the title/action slots from styles/components/view-header.css. The heading, description, optional icon and actions are caller-owned. Use an h1 for the actual page title; the embedded example uses h2 to preserve this document's hierarchy.

Breadcrumbs

Use .wm-nav.wm-breadcrumbs from styles/components/nav.css. Name the navigation, use an ordered list and mark the current item with aria-current="page". Normal anchors work with or without a router.

PreviewImage

Use .wm-preview-image and .wm-preview-image-fallback from styles/components/gallery.css. Provide image alt text and a separately labeled fallback. Missing/failed sources show the fallback; a changed source retries. Loading defaults to lazy.
