Ranked bar list

Relative values with explicit text labels, equivalent to React RankedBarList.

Values relative to a supplied maximum

Use the .wm-ranked-* family from styles/components/ranked-bar-list.css. Supply the order, labels and maximum yourself. Clamp widths to 100%; a zero maximum produces zero-width bars. Values and maximum must be finite and nonnegative; minimum visible width must be between 0 and 100.
